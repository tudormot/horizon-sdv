SDV Voltron Demo Module Standalone

This module provides automated build and validation pipelines for creating the SDV Voltron Demo environment.

The Dockerfile and all image assets are cloned at run time from the internal sdv-demos repository; nothing is vendored in this repository.

Pipeline: voltron-demo-init

Fast preflight, run this first. Verifies that the supplied credentials reach sdv-demos, that the configured revision exists, and that the Dockerfile is at the repository root. Fails in seconds instead of after a multi-gigabyte build.

Pipeline: voltron-demo-execute

Automates end-to-end artifact creation and validation:

  • Step 1: Container Build — Clones sdv-demos and builds the ASfP + CARLA 0.9.15 + SOME/IP image via the shared common-docker-image-build template, pushing to Artifact Registry as voltron-demo.
  • Step 2: Workspace & Candidate Snapshot — Provisions a high-CPU builder workstation, installs CARLA 0.9.15, applies patches and builds AAOS 26Q2, then captures a candidate GCE persistent disk snapshot.
  • Step 3: Automated Test Suite — Launches a GPU-accelerated test workstation and validates CARLA RPC (port 2000) and dual-VM vehicle simulation (launch_2vm).
  • Step 4: Atomic Promotion — On test success, atomically labels the validated snapshot as is-latest=true.

Required parameter: gobGitcookiesB64

Both pipelines clone an internal Git-on-Borg repository, so each run needs your personal Git-on-Borg cookie:

base64 -w0 ~/.gitcookies

Paste the result into gobGitcookiesB64. Cookies expire after roughly 20 hours, so supply a fresh value each run. Argo does not mask parameters, so treat the value as readable by anyone who can read workflows in this namespace.

How to Run

Submit from the Argo Workflows UI, the Developer Portal, or via CLI:

horizon workflow submit --module voltron-demo --template voltron-demo-init \
  --params-json '{"gobGitcookiesB64":"<base64>"}'

horizon workflow submit --module voltron-demo --template voltron-demo-execute \
  --params-json '{"gobGitcookiesB64":"<base64>"}'
