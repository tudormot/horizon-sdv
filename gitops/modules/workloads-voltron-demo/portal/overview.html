SDV Voltron Demo Module Standalone

This module provides automated build and validation pipelines for creating the SDV Voltron Demo environment.

Workflow: sdv-voltron-demo-builder

Automates end-to-end artifact creation and validation:

  • Step 1: Container Build — Builds specialized ASfP + CARLA 0.9.15 + SOME/IP container via Skaffold and pushes to Artifact Registry.
  • Step 2: Workspace & Candidate Snapshot — Provisions high-CPU builder workstation (1000GB SSD), installs CARLA 0.9.15, applies patches and builds AAOS 26Q2, and captures a candidate GCE persistent disk snapshot.
  • Step 3: Automated BATS Test Suite — Launches a GPU-accelerated test workstation and validates CARLA RPC (port 2000) and dual-VM vehicle simulation (launch_2vm).
  • Step 4: Atomic Promotion — On test success, atomically labels the validated snapshot as is-latest=true.

How to Run

Submit the workflow directly from the Argo Workflows UI or via CLI:

argo submit --from wft/sdv-voltron-demo-builder -n workflows
